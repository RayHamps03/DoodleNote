# DoodleNote
Doodle Note is a social website in development
where users have drawing boards to create doodles
of anything they can imagine to share as notes to
other users on the site. 

## Features
This application is a work in progress. Many features and their 
functionality are missing and will be documented here accordingly.

### **Drawing Board**
Users are able to doodle on the application's built in drawing board. This drawing
board uses the [Paper.js](https://paperjs.org/) library to enable the use of multiple
creative tools to build your Doodle Note with.

## Upcoming Features
There are many upcoming features that are planned
to be implemented, including:
- Dashboard home page to show notes as uploaded doodles
- Like and comment system to interact with other user's doodles
- Follower system for users to follow other users to keep up to date on recent notes

## Getting Started
1) Clone or download this repository
2) Download .NET 10 SDK
3) Visual Studio 2026 recommended
4) Open in VS 2026
5) Under tools at the top, click 'NuGet Package Manager' > 'Package Manager Console' (Required for full app functionality) <br>
<img width="522" height="412" alt="Screenshot 2026-03-13 174557" src="https://github.com/user-attachments/assets/849b2a80-54a9-4cb9-9ce9-532d53c15390" /> <br>
6) In the Package Manager Console, type the following: <br>
  `Update-Database`
7) Click run
